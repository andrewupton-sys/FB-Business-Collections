# FB Collections business collections prototype

Single-file prototype (HTML, CSS and JavaScript in one `index.html`). Demo data only; nothing is connected.

## Publish on GitHub Pages

1. Create a new repository (for example `fb-business-collections`).
2. Upload `index.html` (and this README) to the root of the repository.
3. Settings → Pages → Build and deployment → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → Save.
4. After a minute or two the site is live at `https://<your-username>.github.io/fb-business-collections/`.

The page uses Google Fonts (Source Serif 4 and Inter) from fonts.googleapis.com; everything else is inline.
